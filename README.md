# H-Bot Motion Study

Minimal React + Vite visualization that reconstructs the H-Bot mechanism from the repository PNG layers.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Interaction

Use the X, Y, and Z sliders to animate the mechanism:

- **Y** moves the two green traverses on the fixed gray guide bars from `1.PNG`
- **X** moves the blue traverse on the gray bars attached to the green traverses
- **Z** moves the yellow assembly relative to the blue traverse
